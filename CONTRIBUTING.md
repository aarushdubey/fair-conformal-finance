# Contributing to FairTransCP

Thank you for your interest in improving FairTransCP! We welcome contributions that enhance the fairness of conformal prediction in financial domains.

## How to Contribute

1. **Fork the Repository**: Create your own copy of the project.
2. **Create a Feature Branch**: `git checkout -b feature/your-feature-name`.
3. **Implement Your Change**: 
    - Follow the Google Python Style Guide.
    - Add type hints to all new functions.
    - Include unit tests in `tests/unit/`.
4. **Run Tests**: Ensure all tests pass using `pytest`.
5. **Submit a Pull Request**: Describe your changes clearly and link any related issues.

## Contribution Areas
- **New Datasets**: Implementing loaders for other financial benchmarks.
- **New Baselines**: Adding more SOTA conformal prediction methods.
- **Optimization**: Improving the efficiency of the calibration loop.
- **Documentation**: Enhancing the mathematical explanations in the README.
